### Модификаторы доступа в Java

| Модификатор | Класс | Пакет | Наследники | Все |
|-------------|-------|-------|------------|-----|
| `private` | ✅ | ❌ | ❌ | ❌ |
| (default) | ✅ | ✅ | ❌ | ❌ |
| `protected` | ✅ | ✅ | ✅ | ❌ |
| `public` | ✅ | ✅ | ✅ | ✅ |

**Правило большого пальца:**
- Поля — `private`
- Методы — `public` (если нужны снаружи) или `private` (если внутренние)
- Для наследования — `protected`


### Правила абстрактных классов

1. **Нельзя создать объект** абстрактного класса
2. Может содержать **обычные методы** (с реализацией)
3. Может содержать **абстрактные методы** (без реализации)
4. Подкласс **обязан** реализовать все абстрактные методы (или тоже быть абстрактным)
5. Может иметь **конструкторы** (для вызова из подклассов)
6. Может иметь **поля** (как обычные, так и static)


### Когда что использовать?

| Критерий | Абстрактный класс | Интерфейс |
|----------|-------------------|-----------|
| Множественное наследование | ❌ Один класс | ✅ Много интерфейсов |
| Поля с состоянием | ✅ Да | ❌ Только константы |
| Конструкторы | ✅ Да | ❌ Нет |
| Модификаторы доступа | ✅ Любые | ✅ Только public |
| Когда использовать | Общий предок с реализацией | Контракт / возможность |
